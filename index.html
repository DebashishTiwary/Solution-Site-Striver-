Problem Statement: Given an integer N, return the first N rows of Pascal’s triangle. In Pascal’s triangle, each number is the sum of the two numbers directly above it as shown in the figure below: 
            
                class Solution {
                    public List> generate(int numRows) {
                        List> res = new ArrayList>();
                        List row, pre = null;
                        for (int i = 0; i < numRows; ++i) {
                            row = new ArrayList();
                            for (int j = 0; j <= i; ++j)
                                if (j == 0 || j == i)
                                    row.add(1);
                                else
                                    row.add(pre.get(j - 1) + pre.get(j));
                            pre = row;
                            res.add(row);
                        }
                        return res;
                    }
                }

Problem Statement: 1498. Number of Subsequences That Satisfy the Given Sum Condition You are given an array of integers nums and an integer target. Return the number of non-empty subsequences of nums such that the sum of the minimum and maximum element on it is less or equal to target. Since the answer may be too large, return it modulo 109 + 7. Example 1: Input: nums = [3,5,6,7], target = 9 Output: 4 Explanation: There are 4 subsequences that satisfy the condition. [3] -> Min value + max value <= target (3 + 3 <= 9) [3,5] -> (3 + 5 <= 9) [3,5,6] -> (3 + 6 <= 9) [3,6] -> (3 + 6 <= 9) 
            
                    class Solution {
    public int numSubseq(int[] nums, int target) {
        Arrays.sort(nums);
        int count=0;
        int left=0;
        int right=nums.length-1;
        int n=nums.length;
        int mod=1000000007;
        int[] power=new int[n];
        power[0]=1;
        for(int i=1;i < n;i++){
            power[i]=(power[i-1]*2)%mod;
        }
        while(left <= right){
            if(nums[left]+nums[right] <= target){
                count=(count+power[right-left])%mod;
                left++;
            }
            else
            right--;
        }
        return count;
    }
}
Problem Stetment: Given an array arr[] and target sum k, check if there exists a subsequence such that the sum of all elements in the subsequence equals to k. Examples: Input: arr = [10, 1, 2, 7, 6, 1, 5], k = 8. Output: true Explanation: Subsequences like [2, 6], [1, 7] sum upto 8 Input: arr = [2, 3, 5, 7, 9], k = 100. Output: false Explanation: No subsequence can sum upto 10 
                
                    //Pure Recursion Way
                    class Solution {
    public boolean checkSum(int[] arr,int ind,int sum,int k){
        
        if(sum==k)
            return true;
        else if(ind==arr.length)
            return false;
        else if(sum>k)
            return false;
        else{
            return (checkSum(arr,ind+1,sum+arr[ind],k)||
            checkSum(arr,ind+1,sum,k));
        }
        
    }
    public boolean checkSubsequenceSum(int[] arr, int k) {
        // code here
        return checkSum(arr,0,0,k);
    }
}
LC:39-Combination Sum Given an array of distinct integers candidates and a target integer target, return a list of all unique combinations of candidates where the chosen numbers sum to target. You may return the combinations in any order. The same number may be chosen from candidates an unlimited number of times. Two combinations are unique if the frequency of at least one of the chosen numbers is different. The test cases are generated such that the number of unique combinations that sum up to target is less than 150 combinations for the given input. Example 1: Input: candidates = [2,3,6,7], target = 7 Output: [[2,2,3],[7]] Explanation: 2 and 3 are candidates, and 2 + 2 + 3 = 7. Note that 2 can be used multiple times. 7 is a candidate, and 7 = 7. These are the only two combinations. Example 2: Input: candidates = [2,3,5], target = 8 Output: [[2,2,2,2],[2,3,3],[3,5]] 
                
                    class Solution {
    public void solve( List> finalList,int[] ar,int target,int i,List temp){
        if(target==0){
            finalList.add(new ArrayList<>(temp));
            return;
        }
        if(i==ar.length || 0>target){
             return;
        }
        else{
            temp.add(ar[i]);
            solve(finalList,ar,target-ar[i],i,temp);
            temp.remove(temp.size()-1);
            solve(finalList,ar,target,i+1,temp);
        }
    }
    public List> combinationSum(int[] candidates, int target) {
        List> finalList=new ArrayList<>();
        List temp=new ArrayList<>();
        solve(finalList,candidates,target,0,temp);
        return finalList;
    }
}

                    class Solution {
    public void solve(List<List<Integer>> finalList,List<Integer> temp,int[] nums,int index){
                finalList.add(new ArrayList<>(temp));

            if(i!=index && nums[i]==nums[i-1]) continue;
            temp.add(nums[i]);
            solve(finalList,temp,nums,i+1);
            temp.remove(temp.size()-1);
        }
    }

        List<Integer> temp=new ArrayList<>();

    }

LC:216-Combination Sum III-Find all valid combinations of k numbers that sum up to n such that the following conditions are true: Only numbers 1 through 9 are used. Each number is used at most once. Return a list of all possible valid combinations. The list must not contain the same combination twice, and the combinations may be returned in any order. Example 1: Input: k = 3, n = 7 Output: [[1,2,4]] Explanation: 1 + 2 + 4 = 7 There are no other valid combinations. 
                
class Solution {
    public void CS3(List<List> finalList,List temp,int index,int k,int target) {
		if(k==0 && target==0) {
			finalList.add(new ArrayList<>(temp));
		}
        if(target<=0)
            return;
		for(int i=index;i<10;i++) {
			if(target<0 || 0>=k)break;
			temp.add(i);
			CS3(finalList,temp,i+1,k-1,target-i);
			temp.remove(temp.size()-1);
		}
	}
    public List<List> combinationSum3(int k, int n) {
        List<List> finalList=new ArrayList<>();
		CS3(finalList,new ArrayList<>(),1,k,n);
        return finalList;
    }
}
LC:17-Letter Combinations of a Phone Number Given a string containing digits from 2-9 inclusive, return all possible letter combinations that the number could represent. Return the answer in any order. A mapping of digits to letters (just like on the telephone buttons) is given below. Note that 1 does not map to any letters. 
                
                    class Solution {
    public void solve(List<String> finalList,String[] store,String digits,int depth,String val,int index){
        if(depth==0){
            finalList.add(val);
        }
        for(int i=index;i<digits.length();i++){
            String temp=store[digits.charAt(i)-'0'-2];
            for(int j=0;j<temp.length();j++){
                val=val+temp.charAt(j);
                solve(finalList,store,digits,depth-1,val,i+1);
                val= val.substring(0, val.length() - 1);
            }
        }
    }
    public List<String> letterCombinations(String digits) {
        String[] store={"abc","def","ghi","jkl","mno","pqrs","tuv","wxyz"};
        List finalList=new ArrayList<>();
        solve(finalList,store,digits,digits.length(),"",0);
        return finalList;
    }
